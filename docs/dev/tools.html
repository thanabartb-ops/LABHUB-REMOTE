AI Runtime Tools

Public Chat real endpoint call

Secret and Config Tools

Secret Handoff Converter client-side

Converts a pasted config or .env block into a handoff-safe version. Secret values become placeholders. Nothing leaves your browser. See the secret handoff route.

Code Drop Redactor client-side

Scans pasted code or text and masks API keys, tokens, JWTs, and query-string credentials before you share a code drop. See dev code drop.

Provider Connect Checklist owner local

Track connection status per provider. Saved in this browser only (localStorage). See the provider connect route.

Default entries are the real dependencies used by this console. Add or remove freely.

Zapier MCP Tools

ChatGPT Zapier MCP Config owner local reference

Stores your Zapier MCP config URL in this browser's localStorage only. It is never rendered in full, never sent anywhere, and never written into shared files.

MCP Client Template Generator client-side

Generates a Streamable HTTP MCP client config template. No private URL is hardcoded; the URL field is a placeholder for the owner's local reference.

Zapier Export Inspector client-side

Parses a pasted Zapier export JSON and lists zaps, triggers, and actions with auth values masked. No export data is uploaded.

Control Plane Tools

Evidence levels: OBSERVED (seen directly), DECLARED (stated by an authority), VALIDATED (verified against provider logs), INFERRED (derived, not proven). These validators never mark a deployment verified without a provider log reference, and never mark work done without validated evidence.

Evidence Contract Checker

Checks a JSON array of evidence entries for required fields per evidence level. Pass or fail with reasons.

Deployment Verification Gate

A deployment record passes only when it carries a provider, a deployment id, and a provider log reference. Without a log reference this gate always fails.

Declare Done Validator

Rejects done declarations that lack at least one VALIDATED evidence reference. Output includes pass or fail and reasons.

Authority Conflict Detector

Detects resources where different authorities declare different states. Conflicts are listed with the authorities involved.
