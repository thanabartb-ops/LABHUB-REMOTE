Quick Start

Get up and running with lsuperagen in just 5 minutes.

Step 1: Install

Install the lsuperagen CLI using npm or your preferred package manager.

Shell 
npm install -g lsuperagen
lsuperagen --version

Step 2: Authenticate

Create an account and configure your API credentials for secure communication.

Shell 
lsuperagen login
# Follow the authentication flow in your browser

Step 3: Create Your First Project

Initialize a new project with a sensible default configuration.

Shell 
lsuperagen create my-project --template=basic
cd my-project

Step 4: Explore

Run the development server and start building.

Shell 
lsuperagen dev
# Server running at http://localhost:3000
